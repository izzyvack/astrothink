Python & Neural Networks

A beginner-friendly introduction to Python and the ideas behind neural networks. Across four sessions, high school students move from core programming concepts to exploring an AI project.

Summer 2026 session concluded

Who it’s for

Grades 9–12

Format

Online via Zoom

Length

4 sessions

Cost

Free

Program topics

High school students learn Python and the basics of neural networks.

  1. Python foundations

    Get comfortable writing code and working with core Python concepts.

  2. Python libraries

    Explore tools that help you work with data and build projects.

  3. Neural networks

    Understand the basic ideas behind how an AI system learns.

  4. An AI project

    Bring the ideas together in a beginner-level project.
